## API Reference
- [PR analysis data](https://docs.emergetools.com/reference/get_analysis.md): Returns the app size analysis results and any performance test analysis results, as well as PR comments. This endpoint should be used in favor of `/comment`, as it provides a superset of the data. Further, instead of returning a 4xx response when it's not ready yet (which is what /comment does), it will return a 200 response and indicate within the JSON which jobs are still in progress. Must specify either `sha` or `emergeId`.
- [List (max of 10) of uploaded builds](https://docs.emergetools.com/reference/get_apphistory-1.md)
- [get](https://docs.emergetools.com/reference/get_builddetails-1.md)
- [PR comment message](https://docs.emergetools.com/reference/get_comment.md): Get PR comment contents for the difference between two builds.   _Note: Formerly `/getComment`, usages of `/getComment` are still supported but will be deprecated in the future._
- [Request a signed URL for downloading a trace](https://docs.emergetools.com/reference/post_trace.md): Creates a URL for downloading the trace associated with a particular iteration of a performance test span (if available).
- [Get performance test results](https://docs.emergetools.com/reference/get_getperftest.md): Given a test ID, get the performance test results for it
- [Request a signed URL for upload](https://docs.emergetools.com/reference/post_upload.md): Creates a new upload and returns a signed URL to send the upload data.
- [Upload a build with a download link](https://docs.emergetools.com/reference/post_uploadfromlink.md): Creates an upload object and initiates processing.
- [Get snapshot comparison](https://docs.emergetools.com/reference/get_v2_snapshots_diff.md): Returns snapshot comparison data between two builds (head and base), including added, removed, changed, and unchanged snapshots. Can also return data for a single build if no base is specified.
- [Mark snapshot difference as ignored](https://docs.emergetools.com/reference/put_v2_snapshots_ignore.md): Marks a specific snapshot difference as ignored or unignored. When a snapshot difference is ignored, it will not trigger alerts or be counted as a change in snapshot comparisons.
- [Skip snapshot check](https://docs.emergetools.com/reference/post_v1_snapshots_skip.md): Posts a successful Emerge Snapshots GitHub check for a given commit SHA, allowing the PR to merge without running a snapshot comparison. The check will show as completed with a note that it was skipped by the user. This is especially useful in monorepos where the snapshot status check is required but a given PR doesn't include any snapshot-relevant changes.
- [Export Reaper analysis results](https://docs.emergetools.com/reference/post_deadcode-export.md): Returns the Reaper analysis results for a given build
